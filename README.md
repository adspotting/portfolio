# Alexandra Robinson — Product Marketing Portfolio

Source for [Alexandra Robinson’s product marketing portfolio](https://unique-begonia-ee0aa6.netlify.app/).

The site is a self-contained static page: HTML, CSS, and images are bundled in `index.html`, so it can be deployed directly from the repository root with no build step.

## Deploy on Netlify
